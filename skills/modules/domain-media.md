# Domain Module: Media & Creative Production

## Trigger
Use for image/video/audio workflows, editing, generation, transcription, speech, captions, and creative asset pipelines.

## Workflow
1. Clarify the output format, dimensions, duration, quality target, intended audience, and licensing requirements.
2. Identify whether the task needs original generation, authorized source assets, editing, transcription, or conversion.
3. Check asset ownership, consent, model/service terms, and permitted commercial or redistribution use.
4. Define a reproducible workflow: source → processing/generation → review → export → metadata.
5. Preserve source files and make transformations reversible where possible.
6. Check resolution, aspect ratio, frame rate, codec, bitrate, audio levels, captions, and accessibility.
7. Review for artifacts, factual errors, impersonation, privacy leakage, and inappropriate content.
8. Record tool/model versions and export settings.

## Outputs
A production brief, safe processing workflow, reviewed media asset, or export specification.

## Boundaries
Do not use copyrighted source material without permission, misrepresent synthetic media as authentic, or create deceptive impersonations.
