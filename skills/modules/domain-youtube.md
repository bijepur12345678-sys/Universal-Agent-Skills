# Domain Module: YouTube Research & Workflows

## Trigger
Use for YouTube channel/video research, metadata analysis, content planning, authorized analytics, and publishing workflows.

## Workflow
1. Define the channel/topic, date range, questions, and whether the request concerns public data or the user's authorized channel.
2. Prefer the official YouTube Data API and authorized YouTube Analytics API scopes.
3. Respect quotas, API terms, privacy restrictions, rate limits, and content ownership.
4. Separate public video metadata from private channel analytics; do not imply access to private metrics without authorization.
5. Compare titles, descriptions, topics, upload cadence, formats, and publicly available engagement signals.
6. Record data collection time, API version, metrics definitions, and missing fields.
7. Produce recommendations as hypotheses, not guaranteed growth outcomes.
8. For publishing or account changes, preview content and obtain explicit confirmation.

## Outputs
Evidence-based channel/topic report, metadata analysis, content calendar, or authorized publishing plan.

## Boundaries
Do not scrape private analytics, bypass access controls, manipulate engagement, or copy creators' protected content.
