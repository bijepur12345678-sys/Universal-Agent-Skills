# Domain Module: UI/UX & Product Design

## Trigger
Use for user research, UX flows, wireframes, visual systems, prototypes, Figma, accessibility, or interface review.

## Workflow
1. Identify target users, tasks, context, constraints, and measurable usability goals.
2. Map the primary user journey and edge states before styling.
3. Define information hierarchy, navigation, component behavior, and design tokens.
4. Reuse the product's existing design system and component library where possible.
5. Design empty, loading, error, success, and permission states.
6. Include keyboard support, semantic structure, contrast, readable typography, and reduced-motion behavior.
7. Test the design against realistic content, different viewport sizes, and assistive technology needs.
8. Record decisions, trade-offs, and open usability questions.

## Outputs
User-flow map, component/state specification, accessible design guidance, and testable acceptance criteria.

## Boundaries
Do not infer user demographics or sensitive traits without evidence. Do not prioritize decorative effects over clarity or accessibility.
