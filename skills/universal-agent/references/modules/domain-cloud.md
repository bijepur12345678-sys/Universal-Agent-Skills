# Cloud Platforms

## Trigger
Use for cloud architecture, serverless apps, hosted agents, compute, storage, networking, and managed services.

## Workflow
1. Confirm provider, account permissions, region, data residency, free-tier eligibility, and budget ceiling.
2. Separate control plane, runtime, storage, queues, secrets, and observability.
3. Prefer managed/serverless options when quotas and constraints fit.
4. Define least-privilege identities, encryption, network boundaries, backups, and retention.
5. Estimate compute, storage, bandwidth, egress, logs, and request costs.
6. Use reproducible infrastructure configuration.
7. Add health checks, quotas, retries, rate limits, and failure isolation.
8. Test deployment, updates, rollback, restore, and permission boundaries in a non-production environment.
9. Record quotas and teardown steps.

Never create paid resources or claim deployment without explicit authorization and verified results.
