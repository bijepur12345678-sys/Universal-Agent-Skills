# UI/UX & Product Design

## Trigger
Use for user flows, interface design, design systems, wireframes, prototypes, Figma, usability, and accessibility reviews.

## Workflow
1. Identify users, tasks, context, constraints, and measurable usability goals.
2. Map primary journeys and edge states before styling.
3. Define hierarchy, navigation, component behavior, and tokens.
4. Reuse the product's existing design system when possible.
5. Design empty, loading, error, success, and permission states.
6. Include keyboard support, semantic structure, contrast, and reduced motion.
7. Test realistic content, responsive sizes, and assistive technology needs.
8. Record design decisions, trade-offs, and open questions.

Avoid inferring sensitive user traits. Do not prioritize decoration over clarity or accessibility.
