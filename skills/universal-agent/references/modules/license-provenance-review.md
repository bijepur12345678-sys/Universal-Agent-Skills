# License and Provenance Review

## Trigger
Use before copying, adapting, redistributing, or publishing third-party code, Skills, scripts, datasets, assets, or documentation.

## Procedure
1. Identify exact repository, file path, author/contributor, immutable commit or release, and retrieval date.
2. Inspect root and nested LICENSE/NOTICE files, copyright headers, contribution terms, and asset/model/data terms.
3. Determine the license for the exact material. If uncertain, mark review-required and do not redistribute.
4. Record attribution, notices, license text, modification notices, patent terms, and share-alike/source disclosure obligations.
5. Choose reference-only, independent reimplementation, verified redistribution, or reject.
6. Preserve source revision and provenance.

A public repository is not public domain. A root license may not cover every file. This checklist is not legal advice.
