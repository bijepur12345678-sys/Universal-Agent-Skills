# YouTube Research & Workflows

## Trigger
Use for YouTube channel/video research, metadata, authorized analytics, content planning, and publishing workflows.

## Workflow
1. Define channel/topic, date range, questions, and whether data is public or from the user's authorized channel.
2. Prefer official YouTube Data API and authorized Analytics API scopes.
3. Respect quotas, API terms, privacy rules, and rate limits.
4. Distinguish public metadata from private analytics; never imply private metrics are available without authorization.
5. Compare titles, descriptions, topics, cadence, format, and public engagement signals.
6. Record collection time, API version, metric definitions, and missing fields.
7. Treat growth recommendations as hypotheses, not guarantees.
8. Preview content and require confirmation before publishing/account changes.

Do not scrape private analytics, bypass access controls, manipulate engagement, or copy protected creator content.
