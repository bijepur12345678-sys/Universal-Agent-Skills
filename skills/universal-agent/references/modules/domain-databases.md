# Databases

## Trigger
Use for SQL, PostgreSQL, NoSQL, schema design, migrations, indexes, query performance, backups, and data integrity.

## Workflow
1. Identify engine/version, schema, data size, workload, and environment.
2. Review current schema and migrations before changing them.
3. Define keys, constraints, relations, nullability, and lifecycle.
4. Use parameterized queries and server-side authorization.
5. Plan data backfills, locks, rollback, and application-version compatibility.
6. Add indexes based on measured plans and read/write patterns.
7. Test constraints, transactions, concurrent updates, and access policies.
8. Define backup, retention, point-in-time recovery, and restore tests.
9. Minimize sensitive data and avoid exposing records in logs.

Never run destructive production queries without explicit approval and verified backups.
