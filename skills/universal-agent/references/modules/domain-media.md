# Media & Creative Production

## Trigger
Use for image, video, audio, speech, transcription, captions, editing, and creative asset pipelines.

## Workflow
1. Clarify format, dimensions, duration, quality, audience, and licensing needs.
2. Identify whether the task needs original generation, authorized assets, editing, transcription, or conversion.
3. Check asset ownership, consent, model terms, and redistribution rights.
4. Define reproducible steps: source → processing/generation → review → export → metadata.
5. Preserve originals and make transformations reversible where possible.
6. Validate resolution, aspect ratio, frame rate, codec, bitrate, audio levels, captions, and accessibility.
7. Review artifacts, factual errors, privacy leakage, and misleading presentation.
8. Record tool/model versions and export settings.

Do not use copyrighted sources without permission or misrepresent synthetic media as authentic.
