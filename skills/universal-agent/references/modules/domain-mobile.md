# Mobile Development

## Trigger
Use for Android/iOS apps, Flutter, React Native, native APIs, packaging, permissions, and mobile testing.

## Workflow
1. Inspect framework, app structure, minimum OS, signing/build pipeline, and devices.
2. Define navigation, offline behavior, permissions, notifications, and data storage.
3. Request permissions contextually and only when needed; explain why and provide denial paths.
4. Keep secrets off client devices and use secure platform storage for sensitive local data.
5. Design for lifecycle changes, unreliable networks, battery, accessibility, and screen sizes.
6. Add unit, integration, UI, permission, and upgrade tests.
7. Verify build variants, manifest/entitlements, signing, and release artifacts.
8. Document OS/device requirements and store policies.

Do not bypass permission dialogs or commit signing keys and provisioning secrets.
