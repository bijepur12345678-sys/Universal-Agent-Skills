# AI & Machine Learning

## Trigger
Use for LLMs, embeddings, RAG, model evaluation, fine-tuning, inference, or classical ML.

## Workflow
1. Define the task, success metrics, latency, privacy, deployment constraints, and budget.
2. Compare hosted APIs, open models, classical ML, and deterministic software; do not assume an LLM is needed.
3. Verify data rights, sensitivity, retention, and evaluation splits.
4. Compare model versions, licenses, context limits, latency, hardware, cost, and quality.
5. For RAG, specify ingestion, chunking, metadata, retrieval, reranking, citation grounding, and access filters.
6. For fine-tuning, establish a baseline and prevent data leakage.
7. Add structured outputs, timeouts, bounded retries, rate limits, and safe fallbacks.
8. Evaluate task success, factuality, robustness, privacy leakage, and cost.
9. Record exact model/version, configuration, dataset revision, measurements, and failure modes.

Do not expose private data to unapproved providers or claim benchmark superiority without comparable evidence.
