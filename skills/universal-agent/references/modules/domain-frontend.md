# Frontend Development

## Trigger
Use for web UI, components, responsive layouts, state, accessibility, design systems, and client performance.

## Workflow
1. Inspect framework, routes, components, tokens, styles, browser targets, and product conventions.
2. Map user journeys, loading/empty/error/success states, and responsive requirements.
3. Reuse existing components before adding dependencies.
4. Use semantic, keyboard-accessible markup, labels, and focus behavior.
5. Make validation, loading, error, and disabled states explicit.
6. Prevent layout shift and optimize assets/network requests as needed.
7. Check contrast, reduced motion, readable typography, and screen-reader flow.
8. Test narrow/wide viewports, keyboard-only flow, and supported browsers.
9. Verify console, network, and production build.

Do not prioritize decorative polish over usability and accessibility. Never put secrets in client-side code.
