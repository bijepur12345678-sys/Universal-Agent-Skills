# Domain Catalogue

The initial taxonomy contains 22 broad departments. Each can contain many smaller modules, but IDs are stable.

| ID | Department | Example capability families |
|---|---|---|
| ai-ml | AI & Machine Learning | LLMs, embeddings, RAG, evaluation, inference |
| agentic-ai | Agentic AI | planning, memory, reasoning, routing, multi-agent |
| software-engineering | Software Engineering | coding, architecture, debugging, review |
| frontend | Frontend Development | React, Next.js, Vue, CSS, accessibility |
| backend | Backend Development | APIs, services, authentication |
| cloud | Cloud | serverless, Workers, storage, networking, sandboxes |
| devops | DevOps & Infrastructure | CI/CD, containers, deployment, monitoring |
| databases | Databases | SQL, PostgreSQL, NoSQL, schema, migrations |
| research | Research | web research, verification, literature review |
| ui-ux | UI/UX & Design | Figma, design systems, wireframes, usability |
| browser | Browser Automation | browser inspection, automation, web testing |
| desktop | Desktop Automation | accessibility trees, UI automation |
| mobile | Mobile Development | Android, iOS, Flutter, React Native |
| media | Media & Creative | image, video, audio, speech |
| youtube | YouTube | metadata, channel research, analytics |
| automation | Automation & Integrations | APIs, MCP, workflows |
| documents | Documents & Office | PDF, Word, Excel, PowerPoint |
| data-science | Data Science | cleaning, ETL, statistics, visualization |
| security-analysis | Security & Software Analysis | defensive audit, secure coding |
| testing-qa | Testing & QA | unit, integration, E2E, performance |
| education | Education | explanations, learning workflows |
| business | Business & Operations | product, project, marketing, operations |

This is a starting taxonomy, not an exhaustive list of all possible professions or skills. Add domains only when they represent durable capability areas that do not fit existing domains.
